FAMDSプロダクション　プロダクション理念

ABOUT

夢を、現実に。

FAMDSプロダクションは、大阪を拠点に才能を支え育て、世代を超える影響力へと導くプロダクションです。アイドル・VTuber・タレントの育成を通じて、次世代のエンターテインメントを創造します。

MISSION

才能を支え、
本物へ育てる。

「やってみたい」という気持ちを持つすべての人に、プロとして輝くための環境と機会を提供します。参加費・レッスン費無料という仕組みは、経済的な理由で夢を諦めないための、私たちの意思表明です。

VISION

大阪発、
世界へ届ける。

地元大阪から始まり、フェスや大型イベントを経て、日本全国・そして世界へ響く存在を輩出すること。それがFAMDSプロダクションの描く未来です。

VALUE

本気・誠実・
挑戦。

所属するすべてのメンバーと誠実に向き合い、妥協のないステージを追求します。失敗を恐れず挑戦し続けることが、このプロダクションの文化です。

MESSAGE

先輩、私をプロへ。

人の中でも責任感があって、次世代を育てる人材へと成長してほしい。FAMDSプロダクションは、あなたの夢の伴走者でありたいと思っています。一緒に、時代を動かしましょう。

代表 石田あすか
